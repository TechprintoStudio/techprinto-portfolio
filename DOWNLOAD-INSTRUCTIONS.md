# Techprinto Portfolio — corrected image edition

All 38 logos, product images and portrait are included as ordinary local image imports. Vite bundles the images with the site; no Lovable image proxy is required.

## Run locally

1. Extract this ZIP into a new folder. Do not merge it with the older download.
2. Install a current Node.js release and Bun (https://bun.sh).
3. Open a terminal in the extracted folder and run `bun install`.
4. Run `bun run dev` and open the address printed in the terminal.

## Production

Run `bun run build` and deploy the generated output with a TanStack Start-compatible hosting setup. Do not upload just the source ZIP as a static website.

Five products still use fallback icons because no verified image was available: Aegis Stars, MahaStride, eBhojan, eBhojan Restaurants and NSCSTI.

Google Fonts load online. Existing project links and company contact details are preserved.
